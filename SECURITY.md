# Security Policy

## Scope
This repository contains security research notes, checklists, and documentation. It is not a production service and does not authorize testing of third-party systems.

## Reporting a vulnerability in this repository
Please do not open a public issue containing exploit details, credentials, personal data, or sensitive evidence. Contact the repository owner privately through GitHub's private vulnerability reporting feature if enabled, or use a private contact channel published by the owner.

## Research rules
- Test only assets you own or assets explicitly authorized by a current written program policy.
- Re-check scope and exclusions immediately before testing.
- Use test accounts and synthetic data wherever possible.
- Stop if testing risks service availability, privacy, or data integrity.
- Do not access, retain, or disclose other users' data.
- Redact secrets and personal information from notes and commits.

## Supported research
Defensive application security, Android/iOS security review, REST API review, secure engineering, and responsible vulnerability disclosure.
