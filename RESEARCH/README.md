# Research Archive

Store engagement notes here only when they are authorized for this repository and contain no secrets or sensitive personal data.

Suggested structure:
- `YYYY-MM_program-or-project_scope.md`
- `YYYY-MM_program-or-project_findings.md`

Each note should identify the authorization reference and scope. Keep raw captures, credentials, tokens, and sensitive evidence out of Git. Prefer redacted summaries and links to approved private evidence storage.

No findings are claimed by this initial setup.
