# Andy Daily Security Intelligence

The GitHub Actions workflow `Andy Daily Security Research` runs daily and can also be started manually from the Actions tab.

It collects public records from the CISA Known Exploited Vulnerabilities catalog and GitHub Advisory Database. Logical specialist modules triage advisories for Android, iOS, web, API, cloud/infrastructure, and general security relevance.

This is free, passive public-intelligence collection. It is not an always-on AI service, does not call paid model APIs, and does not test any target. Keyword routing may miss relevant advisories or include false positives; consult each original source.
